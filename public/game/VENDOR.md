# Vendored runner game

A pinned snapshot of the Chromium offline dino game, used for the Rome-themed
easter egg on the 404 page. It is served as a static page (`/game/index.html`)
and embedded through an iframe. It is not built or linted by this project.

## Upstream

- Repository: https://github.com/devfolioco/t-rex-runner-game
- Commit: `5c438cf67ce26ea4ef355545c5d1d700067b9863`
- Copied from `resources/dino_game/*.js`, `resources/constants.js` (saved as
  `hidden_class.js`) and `LICENSE`

## Not copied, on purpose

- Upstream sprite PNGs: the Google dino art must never ship. The atlases in
  `images/` are generated by `scripts/generate-rome-sprites.mjs`.
- Upstream `index.html` page chrome, `script.js`, `extra/`, `demo.gif`, the
  sprite-upload UI and the arcade-mode toggle.

## What `index.html` is

Written for this project. It holds the canvas host, the two atlas `<img>`
elements, and the rules the Runner needs (a small subset of Chromium's
offline-page CSS). The `<template id="audio-resources">` with the three
button-press, hit and score sounds is copied unchanged from upstream's
`index.html`, because `Runner.loadSounds()` reads it on the first jump.

## Local patches

Everything else under `public/game/*.js` is byte-identical to upstream at the
SHA above. Each patch is marked with a `Rome patch` comment.

1. `offline.js`, import of `HIDDEN_CLASS`: `'../constants.js'` became
   `'./hidden_class.js'`. Why: upstream's `resources/constants.js` lives one
   directory above the game files, which would resolve to `/constants.js`
   here. It is vendored as `hidden_class.js` (it only exports `HIDDEN_CLASS`).
2. `offline.js`, `Runner.normalConfig.INVERT_DISTANCE` and
   `Runner.slowConfig.INVERT_DISTANCE`: `700` and `350` became `Infinity`.
   Why: night mode inverts the canvas, which breaks the brand colours in the
   sprites. The trigger test is `!(distance % INVERT_DISTANCE)`, and
   `x % Infinity === x`, which is never `0` for a positive distance.
3. `offline.js`, `Runner.init()`: `isDarkMode` is always `false` and the
   `prefers-color-scheme` listener was removed. Why: with night mode off, a
   dark OS theme would otherwise still switch on the moon and stars.
4. `offline-sprite-definitions.js`, `original.LDPI.RESTART` and
   `original.HDPI.RESTART`: `(2, 68)` / `(2, 130)` became `(2, 2)` / `(2, 2)`.
   Why: upstream points below its own atlas (68 and 130 px tall). The
   generated atlases hold the single restart icon at `(2, 2)`.
5. `game_over_panel.js`, `GameOverPanel.animConfig.frames`:
   `[0, 36, ..., 252]` became eight zeros. Why: the atlas has one restart icon
   instead of an 8-frame spin, so the other offsets would draw neighbouring
   sprites. The frame count is kept because it drives the timing.
6. `offline-sprite-definitions.js`, `original.TREX.COLLISION_BOXES`, new
   `original.TREX.DUCKING_COLLISION_BOXES`, and the `CACTUS_SMALL`,
   `CACTUS_LARGE` and `PTERODACTYL` `collisionBoxes`: re-tuned to the Rome
   outlines (legionary standing and ducking, broken column, amphora stack,
   eagle). Why: the upstream boxes fit the dino art. A unit test
   (`tests/unit/rome-game-hitboxes.test.ts`) checks that every box lies inside
   the opaque pixels of its frame in the 1x atlas.
7. `trex.js`, `Trex.collisionBoxes`: reads the runner boxes from the sprite
   definitions instead of hard-coding them. Why: one source of truth for the
   test and the game.

## Service worker

`public/sw.js` passes every request through and caches nothing, so nothing
needs to change there. If caching is ever added, version `/game/images/*`,
otherwise regenerated atlases will be served stale.

## Updating

Re-fetch the files at a new SHA, then re-apply the patches above (search for
`Rome patch`). Regenerate the atlases with `npm run generate:sprites`.
